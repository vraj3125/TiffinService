# TiffinConnect

A marketplace connecting home kitchens in Vadodara, Gujarat with customers who want
a daily tiffin — subscriptions, delivery-radius matching, and admin verification of
every kitchen before it can trade.

```bash
npm install
npm run dev      # http://localhost:5173
```

Copy `.env.example` to `.env.local` and fill in your Firebase keys first. Location
search works with no API key at all.
